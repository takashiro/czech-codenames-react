Introduction
------------

It's a small online app to play Codenames.

Running Environment
-------------------
1. [Server](https://github.com/takashiro/czech-codenames-server)

How to Build
------------
1. Node.js >= 18.x is required.
2. Run `npm ci`.
3. Run `npm start`.
